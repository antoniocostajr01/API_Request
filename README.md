# API Request 🌐

**API Request** is a Swift-based project focused on studying and implementing HTTP requests and API consumption in iOS applications.

The project demonstrates how to communicate with external services, handle asynchronous responses, and manage data retrieved from APIs in a clean and organized way.

## ✨ Features

- 🌍 HTTP requests to external APIs  
- 🔄 Handling asynchronous network calls  
- 📦 Data decoding using Swift’s `Codable` protocol  
- ⚠️ Basic error handling for network and decoding failures  
- 🧩 Clean and simple project structure focused on learning and clarity  

## 🛠 Technologies

- Swift  
- URLSession  
- Codable  
- iOS Development (Xcode)  
- Git & GitHub

4. Run the project

## 🎯 Purpose and Target Audience
This project was created for learning and practicing API communication in Swift.
It focuses on understanding how data flows from an external API into an iOS application, serving as a foundation for more advanced networking and architecture concepts.
